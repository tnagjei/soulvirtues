# Adsterra 接入记录（2026-10-22）

## 决策

AdSense 暂停申请，至少等 2 周再提交。这段时间先接 Adsterra 让现有流量产生收入。两周后的复查提醒已设成一次性自动化任务 adsense-2，到期会提醒重新提交 AdSense。

## 后台配置

- 站点：soulvirtues.org，站点 ID 6141112，分类 Other，状态 Approved
- 广告位：NativeBanner_1，ID 31858818，状态 Active
- 排版：4:1，字体 Inherit，颜色 Inherit（与 CreepyLink 保持一致）
- 脚本：https://bauval.org/21/8d754a16a9484e9a20802712eb3bd162
- 容器：container-8d754a16a9484e9a20802712eb3bd162

只接 Native Banner。没有开启 Popunder（弹窗）、Social Bar（浮动社交栏）和 Adult ads，这三类对体验和审核风险都高。

## 站点改动

1. src/components/AdsterraNativeBanner.astro：新建广告位组件，脚本在接近视口前 400px 才注入，避免拖慢首屏；注入后 8 秒仍未填充则整块移除，不留空白。
2. src/layouts/Layout.astro：移除 Google AdSense 加载脚本（pagead2.googlesyndication.com），站点不再请求任何 AdSense 资源；广告位挂在 main 与 Footer 之间，位置在正文结束、页脚之前，不占首屏；排除 /about/、/contact/、/privacy/、/terms/、/success/ 五类页面，广告会稀释这些页面的信任度，付款成功页更需要干净。
3. src/pages/privacy.astro：第 7 节由 Google AdSense 改写为 Adsterra，说明第三方脚本、Cookie 用途、明确不把答题数据传给广告网络，保留行业退出入口链接。CCPA 服务商列表同步替换。
4. src/components/README.md：补充新组件条目。

## 验证

- npm run build 通过，91 个页面生成。
- 线上 https://soulvirtues.org/ 含广告容器与脚本，/privacy/ 不含，AdSense 脚本计数为 0。
- 375px 与 430px 宽度实测：无横向溢出（scrollWidth 等于视口宽度）；无填充时广告块自动移除，页面不留空白。
- 未验证：广告实际渲染。本机网络把 Adsterra 脚本拦成 0 字节（DNS 返回 198.18.x，直连与代理均如此），CreepyLink 上同样被拦，因此这是本机环境问题，不是代码问题。需要在一台正常网络或手机流量下确认广告是否真的出现。

## 回退

删掉 Layout.astro 里的 AdsterraNativeBanner 与对应 import，再重新构建部署即可。隐私页第 7 节需要同步改回，否则会留下不存在的广告声明。

## 后续观察

- 广告是否在正常网络下出现，以及 4:1 卡片在移动端是否过窄。
- Adsterra 后台的展示量与 CPM 是否正常起量。
- 两周后复查 AdSense 时，广告不影响审核是前提；若广告内容质量失控，优先下广告再过审。

# Payment helpers
- 用途：Waffo 签名与私有报告权限。
- 关键入口：waffo.ts、reports.ts。
- 边界：仅 Pages Functions 使用；凭证只能来自 Cloudflare 环境。
> 更新本目录实现时同步本说明与付款回归。

## Files
- 支付环境由服务器 WAFFO_MODE 决定；正式站与独立测试域名严格匹配，不能用浏览器参数切换环境。
- waffo.ts：有界 API 请求、RSA 签名及回调验签。
- reports.ts：报告快照、D1 存储、访问凭证和订单核验；仅根据本次失败支付替换失效结账链接，保留新链接与已付款保护。
- ai.ts：66题输入、代码确定的回答方向、显式同意、队列、余额及真实模型验证；新正文拒绝计分标签与人群比较，保留旧订单缓存。
- 临时服务故障/超时最多6次，间隔1/5/15/60/240分钟且重复消息遵守下次时间；正文不合格最多3次，余额/认证等永久拒绝立即停止。

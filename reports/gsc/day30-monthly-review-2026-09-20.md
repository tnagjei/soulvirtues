## 4. Counter —— 反证与自我纠错

这一节专门放置与上文叙事冲突、或推翻了我中途假设的证据。

### C-1｜我的「重复 URL 缺陷」假设被证伪 ✅ 已实测推翻

`page-final.json` 里同时出现 19 组「带尾斜杠 / 不带尾斜杠」URL（如 `/es/souls/integrity` 与 `/es/souls/integrity/`），20 个无斜杠 URL 合计 1,305 曝光、仅 4 点击。我据此初步判断存在 canonical 缺失导致的重复索引，并解释了一组蚕食候选（`integridad undertale` 的 3 个 URL）。

**然后我做了 HTTP 实测（curl，只读）**：

| URL | 实测结果 |
|---|---|
| `/es/souls/integrity` | 308 → `/es/souls/integrity/` |
| `/about` | 308 → `/about/` |
| `/souls/kindness` | 308 → `/souls/kindness/` |
| `/compare/integrity-vs-justice` | 308 → `/compare/integrity-vs-justice/` |

**结论：假设错误。** 边缘层（Cloudflare Pages）已用 308 永久重定向完成收敛，**不构成重复 URL 缺陷**。那 1,305 曝光 / 4 点击是索引收敛前的残留记录，占 page 维度曝光 1.4%。**不需要任何代码改动**，只需在下一个窗口确认残留归零。

这一条如果不做实测，就会变成一条"看起来很有道理、实际会白改代码"的建议。

## 7. Confidence ≠ Correctness

**置信度衡量的是"我对这个结论有多确信"，不是"这个结论有多正确"。两者必须分开标注。**

| 结论 | 置信度 | 正确性依据 | 可能错在哪 |
|---|---|---|---|
| 月度总量 16,114 / 87,706 / 18.37% | 高 | 四组维度交叉校验一致 | 只在 GSC 保留行范围内成立；长尾脱敏不可见 |
| 西语贡献 68.66% 点击 | 高 | page 维度 100% 覆盖，合计 16,108 vs property 16,114 | 若未来葡/日/俄起量，占比会稀释，但不改变当前事实 |
| 英文曝光池 57.24% 未变现 | 高 | 同上 | 曝光占比分母含 GSC 多 URL 重复计数 |
| 尖峰是品牌词一次性事件 | 中 | 逐日证据显示品牌词排名 1.5→4.0+，西语词反向改善 | 未排除 Google 评估期/非点击型展示；**未验证** |
| W1 低 CTR 来自非点击型展示 | 低 | 仅有排名相同 CTR 差 5 倍的间接证据 | **纯推断，未验证** |
| 斜杠 URL 不构成缺陷 | **高** | **已 HTTP 实测，308 全量重定向** | 已实测推翻原假设，此结论经反证检验 |
| HSTS 缺失 | **高** | **已 curl 实测确认** | 无 |
| 英文品牌词 CTR 异常原因 | **极低** | 仅排除了 TDH；未看 SERP | 完全未定位，**不可据此行动** |
| `$seo` 报告「无衰减」 | 低 | 它自报 `dataStatus: partial`，4 处 partial | 对比面不完整，结论强度弱于字面 |

**三条硬红线**
1. 任何基于「英文品牌词异常」的行动，必须在看过真实 SERP 之后。**现在没有证据。**
2. `query` 维度只覆盖 82.92% 点击。**不得把未返回的查询当作零。**
3. `$seo` 窗口（08-17~09-15）与本报告窗口（08-18~09-16）不同，**两套数字不可互换引用。**

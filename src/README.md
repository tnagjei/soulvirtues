# src
- 用途：Soul Virtues Extractor 核心源代码目录，包含页面、组件、数据与样式
- 关键入口：src/pages/index.astro, src/components/Quiz.astro
- 边界/依赖：依赖 Astro, Tailwind CSS, TypeScript
> 一旦本目录内容变化，请更新本文件

## Files
- components/：UI 交互与展示组件目录
- data/：66 道题库与七维美德算法数据源
- layouts/：页面外层 HTML 与 SEO Shell 骨架
- pages/：静态路由页面（首页、关于、隐私、条款、联系）
- styles/：全局 Tailwind CSS 样式定义

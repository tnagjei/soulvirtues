# pages
- 用途：Astro 静态站点路由与独立报告阅读页。
- 关键入口：index.astro、success.astro、terms.astro、privacy.astro。
- 边界：报告页无广告/分析，生产须私有凭证与已购验证；法务页说明实际交付及存储。
> 页面协议或数据流变化时更新此文件。

## Files
- success.astro：付款状态、报告目录、英文/西语、PDF 与私有链接工具；仅本地开发启用样例。
- terms.astro：免费测验与收费手册的交付、30 天访问、人工恢复、退款和可选 AI。
- privacy.astro：免费本地处理、购买前报告快照、Waffo 订单信息、D1 保存与可选 AI 数据范围。
- 其他页面：五语言首页、方法说明、特质与对比内容、关于/联系/博客及 404；本次付款修复不改变这些搜索路由。
